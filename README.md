# Rafik's Rugs

Clean Next.js storefront for Rafik's Rugs.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run typecheck
npm run lint
npm run build
```

Product, cart, checkout, search, and custom rug request flows currently run as a front-end prototype. Cart and rug requests persist in browser local storage.
